URL Health Checker
-------------------

A CLI tool to verify the health and accessibility of URLs in Markdown files.

### Installation

```bash
pip install url-health-checker
```

### Usage

```bash
url-health-checker path/to/your/markdown/file.md
```

The tool will scan the provided Markdown file for URLs and check if they are accessible. Any inaccessible URLs will be reported in red, while a green message will be displayed if all URLs are accessible.
